# Task 013: カード表示の一貫性修正 v1

## 目的
200項目化（Task 012）後に目立った、単語カードの次の見え方を改善する。

- 通常表示で英語が見えない（目立たない）ように感じる
- 語句ごとに英語の文字サイズや上下位置がばらつく
- 画像未設定の項目で、画像が欠けた（読み込み中の）ように見える

表示の小さな修正に限定する。語彙、学習ロジック、Recall Cue、ラベル、保存キー / version、操作方法は変更しない。

## 仕様
- Recall の cue 中だけ英語を隠す既存仕様は維持する。通常表示・again・Recall の reveal では英語を表示する。
- 英語の長さによる文字サイズの差を抑える。長い単語や句も幅 390px・320px で切れず読めるようにする。
- 英語、訳、補助句、画像領域の高さと配置をそろえ、表示内容や Recall の状態が変わっても英語の位置が動かないようにする。
- 意味が合う既存の絵文字は維持し、画像未設定項目には共通の控えめな CSS プレースホルダーを表示する。
  無関係な絵文字、外部画像・API・ライブラリは追加しない。

## 修正前の状態（Playwright / Chromium で計測）
- カードは `align-content: center` で、中身の高さに応じて上下中央に寄せていた。
  英語の文字サイズ（=行の高さ）が語ごとに変わるため、英語の上端は 390px 幅で 167〜180px、画像の上端は 285〜298px と語ごとに上下した。
  中央寄せのため、下の操作部・開発用表示の高さが変わるだけでもカード全体がずれた。
- 英語の文字サイズは 390px 幅で、短い語 62.4px に対し長い句（in the long run 等）37.6px 前後と、約1.7倍の差があった。
- Recall の cue 中は英語・訳・画像の行がなくなり、日本語と Cue が上へ詰まる。reveal で英語・訳・Cue・画像が入るため、cue ↔ reveal で配置が大きく変わった。
- 画像未設定の139項目は `◌`（点線の円の文字）を薄く表示しており、読み込み中や画像の欠けに見えやすかった。
- 「英語が見えない」こと自体は、Chromium では再現しなかった（通常表示・again・reveal の英語はすべて visibility: visible / opacity: 1）。
  上記の位置・大きさのばらつき、cue ↔ reveal での配置の入れ替わりが「英語が見えない／見失う」印象につながっていると判断した。

## 実装
変更ファイルは `src/App.tsx`（カード部分の JSX）と `src/App.css`（単語カード・Recall の CSS）のみ。

### カードの行を高さ固定にする
カードを次の固定高さの行で組み、どの状態でも同じ DOM 構造にした。

| 行 | 通常 / again | Recall cue | Recall reveal |
| --- | --- | --- | --- |
| ラベル（既存、高さ固定済み） | new / growth / again | recall | recall |
| 見出し `.headline`（3.8rem） | 英語 | 日本語（従来の大きな日本語） | 英語 |
| 訳 `.translation`（1行） | 日本語 | 空 | 日本語 |
| Cue `.recall-cue`（2行） | 空 | Cue | Cue（薄い色） |
| 画像 `.image-area` | 絵文字 / プレースホルダー | 場所だけ確保して非表示（`visibility: hidden`） | 絵文字 / プレースホルダー |
| 補助文 `.phrase`（1行） | 補助文 | 空 | 補助文 |
| 最下行（既存、高さ固定済み） | タップでもう一度 | 空 | +10 XP |

- 表示する内容は従来と同じ（cue 中に英語・画像・英語の補助文を出さない、reveal で英語・訳・Cue・画像・補助文・XP を出す）。並びだけ固定行にそろえた。
- 英語は見出し行の中で上下中央にそろえるので、文字サイズが変わっても英語の中心位置は変わらない。
- カードは `align-content: start`（上から積む）に変え、上余白を `clamp(8px, 4svh, 40px)` にした。下の操作部や開発用表示の高さが変わってもカード内の位置は動かない。
- 通常表示では Cue 行が空になり、訳と画像の間に約3行分の余白ができる。英語・画像の位置を Recall と通常表示で完全に一致させるための余白として残した。

### 英語の文字サイズ
- 基本サイズを `clamp(3.2rem, 16vw, 5.2rem)` → `clamp(2.6rem, 13vw, 3.2rem)` に下げ、長い語との差を縮めた。
  長い語・句は従来どおり文字数（`--english-length`）に応じて縮め、1行に収める（係数 0.62 は Task 012 と同じ）。
- 文字サイズの範囲（全200項目）
  - 390px 幅: 修正前 約35〜62px（約1.8倍） → 修正後 35.3〜50.7px（約1.4倍）
  - 320px 幅: 修正前 約28〜51px（約1.8倍） → 修正後 28.2〜41.6px（約1.5倍）
- 訳は 1.3rem → 1.2rem、1行（`nowrap`）。最長15文字の訳も 320px 幅で1行に収まることを確認した。
- Recall cue 中の日本語（見出し行）も1行に収め、長い訳は文字数（`--prompt-length`）に応じて縮める。

### 画像領域とプレースホルダー
- 画像領域の高さを `clamp(112px, 18svh, 168px)` → `clamp(88px, 15svh, 148px)` に少し下げ、固定行（空の Cue 行を含む）を足しても全体の高さが増えすぎないようにした。
- 絵文字が設定済みの61項目は変更なし（いずれも意味が合う絵文字であることを確認した）。
- 画像未設定の139項目（データ上の `placeholder: '◌'`）は、文字を出さず CSS で描いた共通の小さな円（36px、`var(--line)` 色）を表示する。
  データ（`words.ts` の `neutralImagePlaceholder`）は変更していない。読み上げ用の `aria-label`（alt）も従来どおり。

## 変更していないもの
語彙データ（`src/data/words.ts`）、学習・選出・Recall のロジック（`src/lib/`）、Recall Cue の文言、ラベル（new / growth / again / recall）、
localStorage の保存キー・version、操作方法（タップ・前へ・次へ・自動周回・速度・音声・補助文）。新しい依存関係・外部画像・API も追加していない。

### ブラウザ確認（Playwright / Chromium、dev サーバー、speechSynthesis はスタブ）
1. **全200項目の流し込み確認**（390×844、320×844）: カードの英語・訳・補助文・Cue と cue 中の日本語に200項目すべてを入れて計測。
   - 英語・訳・補助文・Cue・cue 中の日本語は、どの項目もカードの幅（390px: 350px、320px: 280px）からはみ出さない。
   - 訳・補助文は全項目1行、Cue は全項目2行以内で、固定した行の高さに収まる。
   - 英語の中心位置・画像の上端は全200項目で同じ値（390px・320px とも英語中心 170px / 画像上端 300px）。
2. **実際の遠征での確認**（390×844 で105語、320×640 で105語、320×568 で50語、390×844 ダークモードで60語。「次へ」で進め、途中で1回タップして again を発生させた）
   - 通常・again・Recall reveal のすべてで英語が表示されていた（visibility: visible / opacity: 1）。英語が非表示なのは Recall cue 中だけ。
   - 英語の中心位置・訳・画像・補助文の上端は、通常・again・Recall cue・Recall reveal を通して同じ値（差は 0.01px 未満の端数のみ）。
     例: 390×844 で英語中心 170.3px、画像上端 299.8px、補助文上端 438.4px。
   - 横スクロールの発生なし。コンソールエラーなし。
3. スクリーンショット（通常の絵文字項目・プレースホルダー項目・phrase・again・Recall cue / reveal、390px・320px・ダーク）はプロジェクトファイルの `task-013/` に保存。

## 残課題
- iPhone 実機（Safari、SF Pro フォント）での確認は未実施。文字幅の係数 0.62 は Task 012 と同じで、Inter・SF Pro では収まる見込み。
- 通常表示では Cue 行が空になるため、訳と画像の間の余白が以前より広い。位置をそろえることを優先した。気になる場合は余白の詰め方を別途検討する。
- 「英語が見えない」感覚の原因は、Chromium では非表示として再現しなかったため、位置・大きさのばらつきによる印象と推定して対処した。実機で別の原因（フォント・ブラウザ固有の描画）がないかは未確認。
- 320px 幅では操作部の「自動周回」ボタンの文字が2行に折り返す（今回の修正前から。カード外のため今回は変更していない）。
- 320px 幅の低い画面（320×568、320×640）は修正前から縦スクロールが必要で、固定行の分だけページの高さが少し増えた（320×568 で 738px → 748px、320×640 で 741px → 758px）。390×844 はスクロールなし（修正前と同じ）。
