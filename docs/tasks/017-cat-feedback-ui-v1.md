# Task 017: 記号ボタンと猫の反応を取り入れた学習UI v1

## 目的
学習画面を整理し、理解度を回答する楽しさを小さな猫の反応で作る。
今回は UI と短いイベントまで。出題間隔（Task 016）や猫の長期育成は変更しない。

土台は PR #8 の最新状態（99bca78。Task 016 と基本 Gold の按分を含む）。

## 仕様

### UI
1. 理解度ボタンを左「×」（まだわからない）、右「✓」（わかる）にした。
   - 2つは同じ大きさ（390px 幅で 170×56px、320px 幅で 135×56px）・同じ強調。正誤を表す赤 / 緑は使わない（文字・枠は灰色系）。
   - 選択中（前回の選択を含む）は、太い枠線・背景・記号の太さで示す（`aria-pressed` も付ける）。
   - 記号の下に小さな説明（「まだわからない」「わかる」）を初期表示し、設定の「ボタンの説明」で隠せる。
     隠しても行の高さは残すので、ボタンの大きさは変わらない。読み上げ用の名前（`aria-label`）は常に「まだわからない」「わかる」。
2. 回答ボタンを画面下部に置いた。下から「前へ / 再生・停止 / 次へ / 設定」→「× / ✓」→「猫」の順に並ぶ。
   320×568 でもページのスクロールなしで全部押せる（ページの高さ = 画面の高さ）。
3. 英語・日本語・画像・補助文は上から積む配置のまま。画面下部の状態（猫・選択・説明の表示・設定）で位置は動かない。
4. 猫は回答ボタンのすぐ上の高さ固定（52px）の領域に置いた。単語・ボタンと重ならず、演出は領域の中の絶対配置なのでレイアウトを動かさない。
5. 速度（プリセット・スライダー）・音声 ON/OFF・発音の再生・補助文 ON/OFF・ボタンの説明 ON/OFF を「設定」にまとめた。
   - 設定は下から重ねて開くパネル（`role="dialog"`）。開くとフォーカスが中へ移り、Tab は中だけを巡回する。Escape・「閉じる」・背景のタップで閉じ、フォーカスは「設定」ボタンへ戻る。
   - 開いている間も自動周回は続く。遠征が終わると閉じる。
   - 再生・停止と、前へ / 次へは常に使える。回答したら即座に次へ進む動作は追加していない。
6. 学習中の XP・Gold・Level・「+5」の XP 表示・開発用表示を外した。HUD は「n / 105」と進行の線だけ。
   報酬計算と保存値は変えておらず、遠征完了・帰還・拠点画面の表示はそのまま。開発用表示は学習中以外の画面に残している。

### 猫とイベント（`src/lib/catCompanion.ts`、学習スケジューラーとは独立）
- 待機中は、猫の領域の中を小さく歩いて往復する（歩く4コマ、端で向きを反転）。
- 回答すると、✓ でも × でも同じ小さな反応（約0.36秒跳ねる + ♪ を0.6秒）をし、同じだけ進行する。猫の処理は回答の内容（✓ / ×）を受け取らない。
- 同じ Encounter での連打・回答訂正は、反応も進行もしない（Encounter の通し番号で1回だけ数える）。別の Encounter（再登場や「前へ」で戻った表示を含む）は新しい1回。
- 3回答ごとに「餌を食べる」イベント: その場で止まり、食べる2コマと器、「もぐもぐ」を表示する。
- 暫定値（定数）: `catMealAnswerInterval = 3`、`catMealDurationMilliseconds = 3000`（約3秒）、`catMealMinimumGapMilliseconds = 10000`（開始間隔は最短10秒）、`catReactionMilliseconds = 600`。
- 食事中・待機間隔中の回答も受け付け、出題は続く。開始を待つ食事（保留）は最大1回分で、それ以上は貯めない。
- 未回答で進んでも、猫は何もしない（催促・罰なし）。猫のために回答・停止・追加操作を求めない。
- 猫の処理は自動送りのタイマーに触れない（別のタイマーで、反応の終わり・食事の終わり・保留の食事の開始だけを動かす）。
- 猫の進行は遠征の中だけで持ち、遠征の開始時にリセットする。永続保存しない。
- reduced-motion: 歩行・跳ねる動き・コマ送りを止め、静止ポーズ（歩く1コマ目、食事中は食べる1コマ目と器）で待つ。反応は「♪」、食事は「もぐもぐ」の短い表示で伝える。
- 食事中はスクリーンリーダー向けに「ねこがごはんを食べています」を `role="status"` で伝える（反応は読み上げない）。

  - 元画像の背景は透明で、縁の半透明ピクセルに赤・黄のにじみが乗っていた（黒背景で見ると赤い縁に見える）。不透明度128未満を完全な透明に、それ以上を不透明にして、にじみを落とした（不透明部分に赤いにじみの色は残っていないことを確認）。

## テスト（`npm test`、111件）
`tests/catCompanion.test.ts` に8件を追加した。
- 定数（3回答・3秒・10秒）
- ✓ / × / 混在で、状態（反応・進行）がまったく同じになる
- 同じ Encounter での連打・訂正は反応も進行も増えず、別の Encounter は新しい1回
- 3回答目で食事を始め、3秒で終わる
- 0.5秒ごとに12回答（食事4回分）しても、最初の開始から10秒は次の食事を始めない。保留は1回分だけで、その後は回答がなければ食事は起きない
- 食事中の回答も受け付け、反応は短時間で消える
- 未回答のまま時間が進んでも猫の状態は変わらない
- `showAnswerHints` の保存と旧データの既定値（項目なし・不正な値は表示）

## ブラウザ確認（Playwright / Chromium、dev サーバー、speechSynthesis はスタブ）
390×844 と 320×568 のそれぞれでライト・ダークの4条件で確認した。

1. **配置**
   - 学習中に Lv・XP・Gold・開発用表示は出なかった。
   - × が左・✓ が右で、2つは同じ大きさ。文字・枠・背景は灰色系で、赤 / 緑は使っていない。
   - 未回答・まだわからない・わかる・again・食事中・説明を隠した状態・設定を開いた状態で、次のことを確認した。
     - 英語の中心と画像の上端は1つの値のままだった（390×844: 147.3px / 228.5px、320×568: 136.3px / 217.5px）。
     - 補助文・猫の領域・回答ボタン・移動ボタンは重ならなかった。
     - ページのスクロールはなく、すべてのボタンが画面内に収まった。
2. **説明ラベル**: 設定で隠すと説明は非表示になり、ボタンの読み上げ名（「まだわからない」「わかる」）は残った。設定は再読み込み後も保持された（`showAnswerHints: false`）。
3. **猫のイベント**（停止中）
   - 同じ語で ✓ → × → ✓ → ✓ と押し、次の語で × を押した時点では、食事は始まらなかった（2回分として数えられた）。
   - 3つ目の語で回答すると食事が始まり、約3.05〜3.09秒で終わった。
   - 続けて9回答（3回分）しても、すぐには始まらなかった。最初の開始から約10.05〜10.08秒後に、追加の操作なしで2回目の食事が始まった。
   - 2回目の後は、11秒以上待っても3回目は起きなかった（保留は1回分だけ）。
   - 待機中は猫が領域の中を往復し（端で反転）、歩く4コマが切り替わった。
4. **自動周回への影響**: 0.25秒/語で約8秒間、ほぼ毎語回答した。
   - Encounter は32進んだ（8秒 ÷ 0.25秒 ≒ 32〜33）。食事中も止まらず延びなかった。
   - 設定を開いている間も、1秒で4 Encounter 進んだ。
5. **押し始めた語への記録**（0.25秒/語）: マウス・タッチ・Space を計15回試し、すべて押し始めた語に記録された。
6. **キーの自動リピート**（Task 015 の確認）: Space・Enter の長押し中に語が変わっても、押し始めた語に1回だけ記録された（click も1回）。短押し・マウス・タッチも正しく記録された（両サイズで各20回）。
7. **設定・キーボード・音声**
   - 「設定」にフォーカスして Enter で開き、フォーカスがパネルの中へ移った（`aria-expanded="true"`）。
   - Tab を14回押しても、パネルの中だけを巡回した（閉じる・速度4つ・スライダー・音声・発音を再生・補助文・ボタンの説明）。
   - Escape で閉じてフォーカスが「設定」へ戻り、背景のタップでも閉じた。
   - 音声 ON では、「次へ」と設定の「発音を再生」で表示中の語が読み上げられた。音声 OFF では「発音を再生」が無効になり、「次へ」でも読み上げなかった。
   - キーボード（Enter / Space）で × / ✓ に回答できた。
8. **reduced-motion**
   - 猫の歩行・反転・跳ねる動き・コマ送りのアニメーションは、すべて止まった（左から16pxの位置で静止）。
   - 回答すると「♪」、食事中は食べるポーズ（5コマ目）・器・「もぐもぐ」が表示され、読み上げ用に「ねこがごはんを食べています」が出た。
9. **Task 016 の維持**
   - 空のデータから0.25秒/語で105 Encounter に達して完了した（約26.3秒）。
     - again は6回で、通常の出題で同じ語の重複はなかった。
     - XP +555・Gold +328 で、Task 016 と同じだった。
   - version 1 の旧データ: 移行し、再読み込みで期日が延びなかった。出題順は Task 016 と同じだった。
   - 未回答3語で早期終了した: XP +15・Gold +9。候補0件では「今の復習はありません。」と表示され、報酬は変化しなかった。
10. コンソールエラーはなかった。
