# Task 001: 基本画面と20語データ

## 目的
MVPの最初の実装として、20語データを読み込み、1語ずつ表示できる基本画面を作る。

## 実装範囲

### 1. 単語データ
- 20語を独立したデータファイルで管理する。
- 各単語は少なくとも以下を持つ。
  - 英単語
  - 日本語訳
  - 3語程度の短い補助文
  - 画像参照用の項目
- 表示ロジックに直接ベタ書きしない。

### 2. 基本画面
1語ずつ表示する画面を作る。

表示要素:
- 画像表示領域
- 大きな英単語
- 日本語訳
- 短い補助文

### 3. 操作
- 「前へ」
- 「次へ」

で単語を切り替えられるようにする。

### 4. レスポンシブ
- iPhone相当の画面幅でもレイアウトが崩れないこと。
- タップ領域を小さくしすぎないこと。

## 今回は実装しない
- 音声
- 自動周回
- 速度設定
- 保存機能
- 外部API
- 外部画像取得

## 画像について
- 今回は画像表示領域を作ることを優先する。
- 画像素材が未用意の場合は、公開可能な自作・生成素材へ後で差し替えられる構造にする。
- 著作権や利用条件が不明な外部画像は使わない。

## 完了条件
- 20語データが独立ファイルにある。
- 1語ずつ表示できる。
- 前へ／次へが動く。
- 画像・英単語・日本語訳・補助文の表示領域がある。
- iPhone相当の幅で大きく崩れない。
- `npm run build` が成功する。
- 実装後、変更ファイルと確認結果を簡潔に報告する。
