# Task 003: 自動周回と速度調整

## 目的
英単語を設定した間隔で自動的に切り替える基本的な高速周回機能を追加する。

## 実装範囲

### 1. 自動周回
- 自動周回の開始／停止を切り替えられるようにする。
- 開始中は、設定した間隔ごとに次の単語へ進む。
- 最後の単語まで進んだら最初へ戻る。

### 2. 速度調整
- 0.2秒/語 ～ 3.0秒/語の範囲で調整できるようにする。
- 操作は直感的で、現在値が分かるようにする。
- 細かすぎるUIにはしない。

### 3. プリセット
以下のプリセットを用意する。

- 超高速: 0.25秒/語
- 高速: 0.5秒/語
- 標準: 1.0秒/語
- ゆっくり: 2.0秒/語

### 4. 音声との共存
- 現時点では「設定速度で次へ進む」時間ベースの自動周回を実装する。
- 音声ONの場合でも、今回のTaskでは音声終了を待たない。
- 単語切替時の音声再生は既存Task 002の挙動を維持する。
- 音声キューを不必要に溜めない。

### 5. 手動操作との共存
- 自動周回中でも前へ／次へ操作が破綻しないこと。
- 停止後はその時点の単語を保持する。
- 自動周回を再開したときにタイマーが重複しないこと。

### 6. UI
- 主役である絵・英単語・日本語訳を邪魔しない位置に配置する。
- iPhone相当の画面幅でも操作しやすいこと。
- タップ領域を小さくしすぎないこと。
