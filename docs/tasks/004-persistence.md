# Task 004: 設定と再開位置の保存

## 目的
アプリを閉じたり再読み込みしたあとでも、前回の学習状態をできるだけ自然に再開できるようにする。

MVPではサーバーやアカウント機能を使わず、ブラウザ内の保存だけで実現する。

## 実装範囲

### 1. 保存方法
- `localStorage` を使う。
- 外部サービス、外部API、クラウド同期は使わない。
- 個人情報は保存しない。

### 2. 保存対象
以下を保存する。

- 最後に表示していた単語
- 速度設定
- 音声ON/OFF
- 補助文ON/OFF

### 3. 起動時の復元
- 保存済みデータがある場合は復元する。
- 保存データがない場合は安全な初期値を使う。
- 不正な値や想定外の値が入っていても、アプリが壊れないようにする。

### 4. 保存タイミング
- 対象の設定や表示中の単語が変わったときに保存する。
- 不要な高頻度書き込みは避ける。
- 自動周回中でも保存処理が原因で挙動が不安定にならないこと。

### 5. 補助文ON/OFF
- 補助文の表示／非表示を切り替えられるようにする。
- 現在の表示方針を大きく崩さず、操作はシンプルにする。

### 6. リセット
- MVPでは専用の「全設定リセット」機能は必須にしない。
- ただし、実装上は初期値へ戻しやすい構造にしておく。

## 今回は実装しない
- ログイン
- クラウド同期
- 複数端末同期
- 学習履歴の詳細保存
- 成績管理
- 自動周回の再開状態そのものの保存
- 外部ストレージ

## 完了条件
- ページ再読み込み後も最後に見ていた単語へ戻る。
- 速度設定が復元される。
- 音声ON/OFFが復元される。
- 補助文ON/OFFが復元される。
- 保存データが壊れていても安全な初期値へ戻せる。
- 既存の自動周回、手動送り、音声機能が壊れていない。
- `npm run lint` が成功する。
- `npm run build` が成功する。
- 実装後、変更ファイル・確認内容・残課題を簡潔に報告する。
