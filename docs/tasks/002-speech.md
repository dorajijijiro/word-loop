# Task 002: 英単語の音声再生

## 目的
MVPに英単語の発音再生を追加する。
外部音声APIや外部教材音声は使わず、ブラウザ標準の音声合成を使う。

## 実装範囲

### 1. 音声再生
- 表示中の英単語を英語音声で読み上げられるようにする。
- ブラウザ標準の Speech Synthesis API を利用する。
- 外部API、外部音声ファイル、APIキーは使わない。

### 2. 音声ON/OFF
- 音声の有効／無効を切り替えられるようにする。
- UIはシンプルにし、主表示を邪魔しない位置に置く。

### 3. 手動再生
- 表示中の単語をユーザー操作で再生できるようにする。
- 同じ単語を繰り返し聞けること。

### 4. 単語切替時の挙動
- 前へ／次へで単語が変わったとき、音声ONの場合は新しい単語を読み上げる。
- 連打時に音声が不必要に大量キューへ溜まらないようにする。
- 必要に応じて直前の読み上げをキャンセルしてから新しい単語を再生する。

### 5. iPhoneでの利用
- iPhone Safariを意識し、ユーザー操作を起点とする音声再生制約に配慮する。
- 自動再生がブラウザ制約で動かない場合でも、手動再生は使える構成にする。
- ブラウザ差異がある場合は、無理に回避せず仕様上の制約として報告する。
