# word-loop

**word-loop** は、英単語を短い間隔でくり返し見るための学習用Webアプリです。

英語が得意でなくても使いやすいことを重視し、まずは20語の小さな構成で開発しています。

## できること

現在のMVPでは、次の機能があります。

- 英単語を1語ずつ表示
- 日本語訳を表示
- 短い補助文を表示
- 前へ／次へで単語を切り替え
- ブラウザ標準の音声合成で英単語を読み上げ
- 音声のON/OFF
- iPhone相当の画面幅でも使いやすい表示

現在は20語だけを収録しています。
これは未完成だからではなく、まず使い勝手を確認するために意図的に絞っています。

## これから追加する予定

今後は、実際に使いながら次の機能を追加していく予定です。

- 自動周回
- 0.2〜3.0秒/語の速度調整
- 音声終了待ちモード
- 音声を待たずに進む高速周回モード
- 絵の正式対応
- 再開位置や設定の保存

仕様は開発中に変更する場合があります。

## まず動かす

### 必要なもの

Windowsで開発・動作確認する場合、Node.js と npm が必要です。

このプロジェクトでは、現在以下の環境で動作確認しています。

- Node.js 24系
- npm 11系

### 1. リポジトリを取得する

Gitを使う場合:

```bash
git clone https://github.com/dorajijijiro/word-loop.git
cd word-loop
```

Gitを使わない場合は、GitHubからZIPをダウンロードして展開しても構いません。

### 2. 必要なものをインストールする

```bash
npm install
```

### 3. 開発用サーバーを起動する

```bash
npm run dev
```

表示されたローカルURLをブラウザで開きます。

### 4. 終了する

ターミナルで `Ctrl + C` を押します。

## ビルド確認

公開用のビルドが通るか確認する場合:

```bash
npm run build
```

コードの静的チェック:

```bash
npm run lint
```

## iPhoneで使う場合

このアプリはWebアプリとして開発しています。

最終的にはiPhoneのブラウザでも使えることを目標にしていますが、現在は開発途中です。
音声機能はブラウザやOSに用意されている音声を使うため、声質や挙動が環境によって異なる場合があります。

## 音声について

音声にはブラウザ標準の Web Speech API を使っています。

- 外部の音声APIは使いません
- APIキーは不要です
- 外部教材の音声ファイルは使いません

そのため、利用できる声や発音品質はOS・ブラウザに依存します。

## 画像について

画像は、将来公開できることを前提に扱います。

使用する場合は、次のいずれかに限定します。

- 自作素材
- 生成した素材
- 利用・再配布条件を確認できる素材

出所や利用条件が不明な画像は使用しません。

## プライバシーと安全性

MVPでは、次の方針で開発しています。

- ログイン不要
- 個人情報を扱わない
- 外部AI APIを使わない
- APIキーや秘密情報をブラウザへ埋め込まない
- 不要な外部通信を増やさない
- 将来公開できない素材を非公開開発中にも混ぜない

## 単語データについて

アプリ本体と単語データは分離して管理します。

公開版には、まずサンプルとして20語程度を置く想定です。
将来、自分用の単語データを増やす場合も、アプリ本体を大きく変更せず追加できる構成を目指します。

## 開発方針

- まず20語で実際に使えるものを完成させる
- 機能を増やしすぎない
- 安全性・利用規約・著作権を優先する
- Windowsで開発し、iPhoneでも使えるWebアプリを目指す
- React + TypeScript + Vite を使用する

詳細な仕様は `docs/spec.md` を参照してください。
