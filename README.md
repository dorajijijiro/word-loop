# word-loop

**word-loop** は、英単語を短い間隔でくり返し見るための学習用Webアプリです。

英語が得意でなくても使いやすいことを重視し、小さな構成から段階的に開発しています（現在の内蔵語彙は200項目）。

## できること

現在のMVPでは、次の機能があります。

- 英単語を1語ずつ表示
- 日本語訳を表示
- 短い補助文を表示
- 前へ／次へで単語を切り替え
- ブラウザ標準の音声合成で英単語を読み上げ
- 音声のON/OFF
- 自動周回（0.2〜3.0秒/語の速度調整、4つのプリセット）
- 補助文のON/OFF
- 再開位置や設定の保存（ブラウザ内）
- 単語ごとの表示回数・最終表示日時の記録（ブラウザ内。以前のカードタップ「もう一度見る」の回数も履歴として残しています）
- 1回の学習を「遠征」として区切る（最大105語。今出せる語を出し終えたら105語未満でも終了し、結果を表示。帰還後に次の遠征を開始）
- 遠征中のカード下部の「わかる」「まだわからない」で、単語ごとの理解度を任意で記録できる（本人の自己申告。押さなくても自動周回は止まらない。カードの操作はこの2つだけ）
- 出題は自己申告に基づく（詳細は `docs/tasks/016-answer-based-scheduling-v1.md`）
  - 「わかる」と答えた語は、連続回数に応じて 1 / 3 / 7 / 30 / 90 日後まで出さない（暫定値）
  - 「まだわからない」と答えた語は、別の5語を挟んだ後に again として再登場し、次の遠征でも復習候補になる
  - 優先順位は「再登場の時期が来た まだわからない」→「復習候補（期日が来たわかる・まだわからない）」→「未回答の語（表示回数の少ない語から）」
  - 未回答の語は理解済みとも未理解とも扱わない。同じ遠征では、回答なしで同じ語を繰り返し出さない
  - 今出せる語が1つもなければ遠征を始めず、「今の復習はありません」と表示する
- new / growth / familiar の分類はラベル・XP の表示にだけ使い、出題の判断には使わない
- 遠征を完了すると XP と Gold を獲得し、累積XP・所持Gold・完了遠征数をブラウザ内に保存
- 累積XPから算出するプレイヤーレベル（拠点画面・遠征中・帰還画面に表示、遠征でレベルが上がると帰還画面で「LEVEL UP」）
- 遠征中は英語・日本語・絵を常に同時に表示する（英語を隠して思い出す Recall Encounter は現在無効。詳細は `docs/tasks/014-disable-recall-v1.md`）
- 拠点画面 → 遠征（進行度・Level・XPの小さなHUD、new / growth / again の控えめなラベル）→ 遠征完了 → 帰還 → 次の遠征、の流れ
- iPhone相当の画面幅でも使いやすい表示（ダークモード対応）

画面下部の「開発用」表示は動作確認のためのもので、最終的なUIではありません。

現在は200項目（基礎・中級・やや難しい語と、phrase / phrasal verb）を収録しています。
既知語・曖昧な語・未知語が混ざった状態で学習体験を確かめるための規模で、日本語訳・補助文・Recall Cue はすべて自作です（詳細は `docs/tasks/012-vocabulary-expansion-v1.md`）。

## まず動かす

### 必要なもの

Windowsで開発・動作確認する場合、Node.js と npm が必要です。

このプロジェクトでは、現在以下の環境で動作確認しています。

- Node.js 24系
- npm 11系

### 1. リポジトリを取得する

Gitを使う場合:

```bash
git clone https://github.com/dorajijijiro/word-loop.git
cd word-loop
```

Gitを使わない場合は、GitHubからZIPをダウンロードして展開しても構いません。

### 2. 必要なものをインストールする

```bash
npm install
```

### 3. 開発用サーバーを起動する

```bash
npm run dev
```

表示されたローカルURLをブラウザで開きます。

### 4. 終了する

ターミナルで `Ctrl + C` を押します。

## ビルド確認

公開用のビルドが通るか確認する場合:

```bash
npm run build
```

コードの静的チェック:

```bash
npm run lint
```

選出ロジック・報酬計算の自動テスト（Node.js 標準のテスト機能を使用）:

```bash
npm test
```

## iPhoneで使う場合

このアプリはWebアプリとして開発しています。

最終的にはiPhoneのブラウザでも使えることを目標にしていますが、現在は開発途中です。
音声機能はブラウザやOSに用意されている音声を使うため、声質や挙動が環境によって異なる場合があります。

## 音声について

音声にはブラウザ標準の Web Speech API を使っています。

- 外部の音声APIは使いません
- APIキーは不要です
- 外部教材の音声ファイルは使いません

そのため、利用できる声や発音品質はOS・ブラウザに依存します。

## 画像について

画像は、将来公開できることを前提に扱います。

使用する場合は、次のいずれかに限定します。

- 自作素材
- 生成した素材
- 利用・再配布条件を確認できる素材

出所や利用条件が不明な画像は使用しません。

## プライバシーと安全性

MVPでは、次の方針で開発しています。

- ログイン不要
- 個人情報を扱わない
- 外部AI APIを使わない
- APIキーや秘密情報をブラウザへ埋め込まない
- 不要な外部通信を増やさない
- 将来公開できない素材を非公開開発中にも混ぜない

## 単語データについて

アプリ本体と単語データは分離して管理します。

内蔵データは `src/data/words.ts`（現在200項目）。公開版にどの範囲を同梱するかは今後決めます。
将来、自分用の単語データを増やす場合も、アプリ本体を大きく変更せず追加できる構成を目指します。

## 開発方針

- まず20語で実際に使えるものを完成させる
- 機能を増やしすぎない
- 安全性・利用規約・著作権を優先する
- Windowsで開発し、iPhoneでも使えるWebアプリを目指す
- React + TypeScript + Vite を使用する

詳細な仕様は `docs/spec.md` を参照してください。
