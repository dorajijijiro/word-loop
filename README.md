# word-loop

**word-loop** は、英単語を短い間隔でくり返し見るための学習用Webアプリです。

大卒の社会人が日常・ビジネスで困らない語彙を身につける「大人の学びなおし」を目標に、小さな構成から段階的に開発しています（現在の内蔵語彙は約1,500項目）。

## できること

現在のMVPでは、次の機能があります。

- 英単語を1語ずつ表示
- 日本語訳を表示
- 短い補助文を表示
- 前へ／次へで単語を切り替え
- 表示中の英単語・句の発音を、Kokoro で事前生成した音声（MP3）で再生（Task 021。カードが切り替わったときと「発音を再生」で再生）
- 音声のON/OFF
- 自動周回（0.2〜3.0秒/語の速度調整、4つのプリセット）
- 補助文のON/OFF
- 再開位置や設定の保存（ブラウザ内）
- 単語ごとの表示回数・最終表示日時の記録（ブラウザ内。以前のカードタップ「もう一度見る」の回数も履歴として残しています）
- 1回の学習を「遠征」として区切る（最大105語。今出せる語を出し終えたら105語未満でも終了し、結果を表示。帰還後に次の遠征を開始）
- 遠征中は画面下部の ×（まだわからない）/ ✓（わかる）で、単語ごとの理解度を任意で記録できる（本人の自己申告。押さなくても自動周回は止まらない。ボタンの小さな説明は設定で隠せる）
- 回答ボタンの上を小さな茶トラ猫が歩き、回答すると小さく反応する。3回答ごとに餌を食べる短いイベントがある（✓ でも × でも同じ。猫の状態は保存しない。詳細は `docs/tasks/017-cat-feedback-ui-v1.md`）
- 速度・音声・発音の再生・補助文・ボタンの説明は「設定」にまとめ、学習中の常設操作は 前へ / 再生・停止 / 次へ / 設定 だけにした
- 出題は自己申告に基づく（詳細は `docs/tasks/016-answer-based-scheduling-v1.md`）
  - 「わかる」と答えた語は、連続回数に応じて 1 / 3 / 7 / 30 / 90 日後まで出さない（暫定値）
  - 「まだわからない」と答えた語は、別の5語を挟んだ後に again として再登場し、次の遠征でも復習候補になる
  - 優先順位は「再登場の時期が来た まだわからない」→「復習候補（期日が来たわかる・まだわからない）」→「未回答の語（表示回数の少ない語から）」
  - 未回答の語は理解済みとも未理解とも扱わない。同じ遠征では、回答なしで同じ語を繰り返し出さない
  - 今出せる語が1つもなければ遠征を始めず、「今の復習はありません」と表示する
- new / growth / familiar の分類はラベル・XP の表示にだけ使い、出題の判断には使わない
- 遠征を完了すると XP と Gold を獲得し、累積XP・所持Gold・完了遠征数をブラウザ内に保存
- 累積XPから算出するプレイヤーレベル（拠点画面・遠征中・帰還画面に表示、遠征でレベルが上がると帰還画面で「LEVEL UP」）
- 遠征中は英語・日本語・絵を常に同時に表示する（英語を隠して思い出す Recall Encounter は現在無効。詳細は `docs/tasks/014-disable-recall-v1.md`）
- 拠点画面 → 遠征（進行度だけの小さなHUD、new / growth / again の控えめなラベル。XP・Gold・Level は結果・拠点画面で表示）→ 遠征完了 → 帰還 → 次の遠征、の流れ
- iPhone相当の画面幅でも使いやすい表示（ダークモード対応）
- 拠点画面の「音声の試聴（Kokoro）」から、全語彙の Kokoro 音声を検索・試聴できる。ブラウザ標準の読み上げとの聴き比べもここに残している（学習の記録には影響しない。詳細は `docs/tasks/019-kokoro-audio-preview.md`・`docs/tasks/020-kokoro-vocabulary-audio.md`）

画面下部の「開発用」表示は動作確認のためのもので、最終的なUIではありません。

現在は1,489項目（単語と phrase / phrasal verb）を、日常基礎・日常応用・ビジネス基礎・ビジネス応用の4ランクに分けて収録しています。
中学レベルの語は既知として出題しません。未回答の語は易しいランクから順に出し、カードにはランクを小さく表示します。
日本語訳・補助文は AI で作成したもので、確認方法と既知の注意点は `docs/tasks/018-adult-vocabulary-ranks-v1.md` に記録しています。

## まず動かす

### 必要なもの

Windowsで開発・動作確認する場合、Node.js と npm が必要です。

このプロジェクトでは、現在以下の環境で動作確認しています。

- Node.js 24系
- npm 11系

### 1. リポジトリを取得する

Gitを使う場合:

```bash
git clone https://github.com/dorajijijiro/word-loop.git
cd word-loop
```

Gitを使わない場合は、GitHubからZIPをダウンロードして展開しても構いません。

### 2. 必要なものをインストールする

```bash
npm install
```

### 3. 開発用サーバーを起動する

```bash
npm run dev
```

表示されたローカルURLをブラウザで開きます。

### 4. 終了する

ターミナルで `Ctrl + C` を押します。

## ビルド確認

公開用のビルドが通るか確認する場合:

```bash
npm run build
```

コードの静的チェック:

```bash
npm run lint
```

選出ロジック・報酬計算の自動テスト（Node.js 標準のテスト機能を使用）:

```bash
npm test
```

## 音声について

通常の遠征の発音は、Kokoro（hexgrad/Kokoro-82M、Apache License 2.0）で事前生成した MP3 を再生します（Task 020 で生成、Task 021 で遠征に採用）。

- 音声は開発時に `tools/kokoro/` の手順で生成し、アプリは生成済みの MP3 を再生するだけです（Kokoro 本体・モデルはブラウザへ配布しません）
- 外部の音声API・APIキーは使いません。外部教材の音声ファイルも使いません
- 全語彙の MP3 を起動時に読み込むことはせず、表示中の語の音声だけを読み込みます
- 再生できなかったときは画像枠の右上に小さく表示し、ブラウザ標準の音声合成へは切り替えません
- 音質は採用しましたが、全項目の発音を人が聴いて確認したわけではありません（要判断・要確認の語は `docs/tasks/020-kokoro-vocabulary-audio.md`）
- ブラウザ標準の音声合成（Web Speech API）は、試聴画面での聴き比べにだけ残しています
- 生成音声のクレジット: Audio generated with Kokoro-82M by hexgrad (Apache License 2.0).

## プライバシーと安全性

MVPでは、次の方針で開発しています。

- ログイン不要
- 個人情報を扱わない
- 外部AI APIを使わない
- APIキーや秘密情報をブラウザへ埋め込まない
- 不要な外部通信を増やさない
- 将来公開できない素材を非公開開発中にも混ぜない

## 単語データについて

アプリ本体と単語データは分離して管理します。

内蔵データはランクごとに `src/data/vocabulary/*.ts` に分け、`src/data/words.ts` でまとめています（現在1,489項目）。公開版にどの範囲を同梱するかは今後決めます。
将来、自分用の単語データを増やす場合も、アプリ本体を大きく変更せず追加できる構成を目指します。
